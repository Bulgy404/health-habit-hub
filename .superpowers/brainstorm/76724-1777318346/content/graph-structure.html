What does the graph show?

Neo4j has Habit nodes connected to BCIOConcept nodes via Context. Which topology do you want to render?

A

Habits only — real edges

Only Habit nodes visible. Two habits are connected with an edge if they share a BCIOConcept in Neo4j. Graph looks similar to now, but edges are real database relationships, not just same-category guesses.

~200–500 habit nodes, edges = shared concept

B

Habits + Concept hub nodes

Both Habit nodes AND BCIOConcept nodes visible. Habits radiate out from their concept hubs. You can clearly see which habits belong to the same concept cluster. Concept nodes act as "stars" with habits as planets.

Concept nodes = orange/pink hubs; habit nodes orbit them

About the renderer

Either option will use flutter_graph_view (richer 3D-like visuals, sphere/force layouts) as the primary renderer, with the existing custom canvas as fallback if the package doesn't support the dataset size well.
