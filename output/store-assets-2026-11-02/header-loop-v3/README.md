# Growing knowledge graph — header animation v3

Eight-second seamless loop at 3840 × 1646, 30 fps, H.264, silent. Ten new nodes appear in staggered sequences, twelve connections draw between them, and small signals travel along completed connections. Branches gently move, then recede to the original graph before the cycle repeats.

The approved v4 heart and outlined Figtree wordmark are reused unchanged and remain stationary. New nodes and connections stay outside the central brand area.

`health-habit-hub-growing-graph-8s-v3.mp4` is the main export. `preview-120.png` and `growing-graph-poster.svg` show the graph at four seconds. The Python source reconstructs every frame from vectors, without resizing or inventing app UI.
