# Health Habit Hub — store asset review pack

November 2, 2026. Uses the approved logo-first green identity and the new growing knowledge graph.

## Included

- **01_brand** — Apple universal (5244 × 2950) and search (3840 × 2560) PNG/SVG artwork, transparent white/green identity exports, and the existing app icon exported as an opaque full-square 512px Play icon.
- **02_header_motion** — seamless 8-second, 3840 × 1646, 30fps header loop. Ten nodes appear, twelve connections draw, and small signals move. The logo/wordmark stay fixed. Complete graph poster and validation included.
- **03_ios_originals** — 36 genuine current-app Xcode simulator captures: six views × English/German × iPhone 18 Pro (1206 × 2622), iPhone 18 Pro Max (1320 × 2868), and iPad Pro 13-inch M5 (2064 × 2752).
- **04_ios_mockups** — 36 branded PNGs with matching self-contained SVGs. Open `mockup-contact-sheet.jpg` for the overview.
- **05_ios_previews** — English/German 25-second app recordings exported at 886 × 1920, H.264, 30fps, 750 frames. These use the actual app, not device animation. Native source recordings are retained.
- **06_google_play_concepts** — experience-led 1024 × 500 feature graphics in English/German. Their shared Flutter content comes from the current capture; Android parity review remains pending.
- **ASSET-PLAN.md** — format checklist, source audit, remaining work, and official specification links.

## App capture provenance

The current app is version 1.3.1+7, built in an isolated copy using Flutter 3.47.4 / Xcode 27.0 and rendered on iOS 27.0 simulators. The app widgets, theme, navigation, and translations are retained. Fictional examples provide the account data, habit logs, scores, and graph contents. No participant data or production backend was used. Shipping source files were not modified.

The mockups are review drafts. In particular, the current German New Habit screen retains two English option labels, and the phone Explore view shows the app's default zoom into the pannable graph. Original captures are included so these details are clear.

## Still pending

**iPhone Duo:** full Xcode 27.1+ and the corresponding simulator support are needed. The installed standalone Command Line Tools are 27.2, but the Xcode app remains 27.0 and has no Duo device type/runtime. This pack contains no invented or resized Duo screenshots.

**Android store finals:** no Android system image or virtual device is installed. Genuine Android captures and the final Google-specific teaser remain pending; the feature graphics here are concepts. Nothing has been uploaded to a store or YouTube.

File hashes are listed in `file-manifest.json`. Earlier OneDrive header versions are preserved separately.
