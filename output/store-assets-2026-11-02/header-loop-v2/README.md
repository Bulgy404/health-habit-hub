# Header loop v2 — stronger movement

Based on the approved v4 green static artwork. Logo and outlined Figtree wordmark stay fixed; the graph background now drifts ±112 pixels horizontally and ±64 pixels vertically across an eight-second cycle. This replaces the earlier ±16 / ±10 pixel motion proof with approximately seven times the travel.

`health-habit-hub-header-loop-8s-v2.mp4`: 3840 × 1646, H.264 yuv420p, 30 fps, 240 frames, eight seconds, no audio. The graph layer has 160 pixels of overflow on each edge to avoid exposed boundaries. The continuous sinusoidal animation loops without a discontinuity.

`header-loop-motion-peak.png` shows the maximum displacement at two seconds. `validation.json` records metadata; the build script also checks a full decode. Earlier versions are preserved.

This is a creative header animation, not a real-UI App Store app preview. No storefront submission has been made.
