# Branded mockups from current app captures

36 review mockups: six current app views × English/German × iPhone medium, iPhone large, and iPad. Each PNG retains its device category's required native dimensions and has no alpha channel. Matching SVGs embed the actual screenshot and outlined Figtree captions, with no font or image dependencies.

The approved green field, heart-and-network identity, and graph motifs surround the current app UI. Screens are resized proportionally inside simple frames; app content is not redrawn or altered. Captions use existing app feature names.

`mockup-contact-sheet.jpg` is an overview, and `mockup-manifest.json` records source originals and export dimensions. The matching raw captures are under `../capture/raw/`.

Review the current-app notes in `../capture/README.md`, especially the German New Habit choice labels and phone graph zoom. No Duo or Android compatibility is implied. These are review assets, not assets already approved or submitted by a store.
