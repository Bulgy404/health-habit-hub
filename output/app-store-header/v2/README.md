# App Store header — graph direction

Original flat vector composition, replacing the rendered still-life direction. The editable SVG exports directly to 3840 × 1646 PNG without upscaling.

Uses the exact seven dimension colors in `mobile/lib/widgets/bubble_graph/bubble_graph_data.dart`, brand primaryDark from `docs/design-system.md`, and the habit-to-context relationship from `docs/assets/architecture/neo4j-graph-schema.svg`. The graph depicts an illustrative walking habit; it does not expose participant data or imply live metrics. Social, location, and state are shortened display labels for the app's corresponding dimensions.

Files:
- `health-habit-hub-header-v2.svg`: editable vector artwork.
- `health-habit-hub-header-v2.png`: full-resolution App Store header export.
- `create-header.py`: reproducible vector source.

English text is embedded in this version. Localize the labels for other storefront languages. Preview cropping in App Store Connect before submission. Nothing has been uploaded.
