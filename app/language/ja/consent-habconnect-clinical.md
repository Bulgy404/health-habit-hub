# 追加同意説明文書 — HabConnect 臨床研究群

> 正文はドイツ語版です。本文書は参考のための翻訳です。

本同意は、HabConnect 研究の一般同意説明文書に**追加して**適用されます。一般同意
を置き換えるものではありませんが、その**一部の記載を変更します**。変更点は
「一般同意からの変更点」の節に記載しています。

本文書をお渡ししているのは、⟦協力医療機関の名称⟧ を通じて参加のご案内を差し上げ
ており、この研究群では本人確認が必要となるためです。

**管理責任者：** ドレスデン工科大学 経済学部 Digital Health 研究グループ
**倫理審査：** ⟦倫理審査の受付番号および承認日⟧

## 要点

- **何が違うのですか。** この研究群では、研究チームはどなたが参加しているかを把握
  します。一般公開版のアプリではそうではありません。
- **なぜですか。** 研究期間中に健康上の問題が判明した場合にご連絡できるようにする
  ため、また臨床研究は規制当局の査察を受けられる必要があるためです。
- **誰が氏名を見ますか。** 実施医療機関の研究スタッフと研究運営者のみです。データを
  解析する研究者は**見ません**。
- **氏名はどこに保管されますか。** 研究データベースではなく、分離された暗号化済みの
  身元登録簿に保管されます。
- **撤回できますか。** いつでも、理由を示すことなく撤回できます。

## 一般同意からの変更点

一般同意説明文書には、すべてのデータは**完全に匿名化して**収集し、氏名も生年月日も
保存しないと記載されています。**この研究群ではそのとおりではありません。**正しくは
次のとおりです。

| 一般同意                         | この研究群                                                           |
| -------------------------------- | -------------------------------------------------------------------- |
| 氏名も生年月日も保存しない       | 氏名・生年月日・連絡先を、研究データとは分離して保存します           |
| 本人への紐づけはできない         | 紐づけは可能ですが、下記の条件を満たす場合に限り、必ず記録が残ります |
| 特定のデータのみの削除はできない | 登録簿の記録は個別に削除できます。研究データは仮名のまま保持されます |

一般同意のその他の点 — 参加は任意であること、研究の流れ、研究および公開習慣
データベースでのデータ利用、**匿名化・集計済みデータのみ**の国際共有 — は変更なく
適用されます。

## 収集する情報と保管場所

| 情報                                           | 保管場所                             |
| ---------------------------------------------- | ------------------------------------ |
| 氏名、生年月日、連絡先、実施医療機関の割り当て | **分離された暗号化済みの身元登録簿** |
| 研究データ（習慣、推奨、質問票）               | プラットフォームの研究データベース   |

いずれのシステムもドレスデン工科大学のサーバー上にありますが、互いに分離して稼働し、
別々のデータベースを使用します。

研究データベースにお名前は**含まれません**。`TUD-ICU01-0042` のような研究コードのみ
を保持します。このコードはアプリの設定画面でご自身でも確認できます。研究チームに
連絡される際にお伝えください。

**診療記録からデータを取り込むことはありません。**研究に入る情報はすべて、ご自身が
アプリに入力されたものです。医療機関が研究データにアクセスすることはありません。

### 登録簿の保護方法

- 各項目は個別に暗号化して保存されます（AES-256-GCM）。データベースの複製だけでは、
  鍵がなければ読み取れません。
- 鍵はデータベース内にはなく、分離して保管されます。
- 登録簿の閲覧権限は個別に付与されます。研究チームに所属しているだけでは足りません。
- **複数名を一度に開示する機能はありません。**技術的に、紐づけは常に一名ずつしか
  行えません。

## 誰が、どのような条件で本人を特定できるか

研究データを解析する研究者は、あなたが誰であるかを**特定できません**。これは文書上の
約束にとどまりません。研究データへのアクセス権を持つ者に、システムは登録簿への
アクセスを与えません。

紐づけは、以下の**すべて**を満たす場合に限り可能です。

1. 文書化された理由があること — 重篤な有害事象、安全性報告、規制当局の査察、
   ご本人からの依頼、またはデータの誤りの訂正、
2. **第二の担当者**が承認すること。申請した本人が自ら承認することはできません、
3. 開示は**期間を限定**（通常 60 分）し、明示された項目とご本人のみに限られること。

**すべての紐づけは恒久的に記録されます** — 日時、理由、実施者、参照した項目とともに
記録され、事後に検証できます。この記録は研究運営者であっても改変できません。

## 機関内で誰が何を見るか

| 役割                       | 氏名を見る                 | 研究データを見る |
| -------------------------- | -------------------------- | ---------------- |
| 実施医療機関の研究スタッフ | 見る                       | 見ない           |
| 研究運営・モニタリング     | 承認された申請の範囲でのみ | 見ない           |
| 解析担当の研究者           | 見ない                     | 見る（仮名化）   |

## 保管期間

身元登録簿の記録は、研究終了後、倫理審査で定められた保管期間の経過後に削除されます
（⟦倫理審査で定められた保管期間⟧）。それ以降、研究データをご本人に紐づけることは
恒久的にできなくなります。

仮名化された研究データは、一般同意説明文書に記載のとおり、長期的な科学研究のために
継続して保管されます。

## 撤回と削除

同意はいつでも、理由を示すことなく撤回できます。撤回によって不利益が生じることは
なく、特に医療上の治療や経過観察に影響することはありません。

撤回すると何が起こるかを、あらかじめお伝えします。

- **身元登録簿の記録が削除されます。**その後は、研究チームを含め、誰も研究データを
  ご本人に紐づけることができなくなります。
- すでに収集された**研究データは仮名のまま保持され**、解析が続けられます。これは
  意図的なものです。すでに公表された、または解析に組み込まれた結果は追跡可能で
  なければならないためです。
- この削除は**取り消せません。**後日あらためて参加を希望される場合は、新規の参加と
  してのみ可能です。

仮名化された研究データの削除も希望される場合は、研究チームに直接ご連絡ください。
登録簿の記録が残っている間は当該データを特定して削除できますが、削除後はできません。
