# Health Habit Hub — Teilnehmerhandbuch

Willkommen bei Health Habit Hub. Dieses Handbuch führt Sie durch alles, was Sie als Studienteilnehmer wissen müssen. Die Lektüre dauert etwa fünf Minuten.

---

## Was Sie benötigen

- Ihre **Token-Karte** — von Ihrem Studienkoordinator ausgehändigt. Sie enthält einen QR-Code sowie einen aufgedruckten Benutzernamen und ein Passwort.
- Ein Smartphone oder Tablet (Android oder iOS) oder einen Webbrowser auf Ihrem Computer.
- Eine Internetverbindung (WLAN oder mobile Daten).

---

## 1. Erste Anmeldung

**Schritt 1.** Öffnen Sie die Health Habit Hub App (oder rufen Sie die von Ihrem Studienkoordinator angegebene URL auf).

**Schritt 2 — QR-Code scannen (am einfachsten).** Tippen Sie auf dem Anmeldebildschirm auf die QR-Scan-Schaltfläche und richten Sie Ihre Kamera auf den QR-Code auf Ihrer Token-Karte. Benutzername und Passwort werden automatisch ausgefüllt.

**Schritt 3 — Oder manuell eingeben.** Falls das Scannen nicht funktioniert, geben Sie Benutzername und Passwort genau so ein, wie sie auf Ihrer Token-Karte aufgedruckt sind. Benutzernamen sehen aus wie `hhh-1234`. Groß-/Kleinschreibung wird unterschieden.

**Schritt 4.** Tippen Sie auf **Anmelden**. Die App verbindet sich mit dem Server und Sie gelangen zum Startbildschirm.

> Bewahren Sie Ihre Token-Karte sicher auf. Wenn Sie sie verlieren, wenden Sie sich an Ihren Studienkoordinator.

### Konto auf einem neuen Gerät wiederherstellen

Beim Onboarding wird Ihnen einmalig eine **Wiederherstellungsphrase** angezeigt — eine Folge von Wörtern, die Ihr Konto eindeutig kennzeichnet. Notieren Sie sie an einem sicheren Ort. Wenn Sie die App auf einem neuen Gerät installieren, können Sie über **Konto wiederherstellen** auf dem Anmeldebildschirm diese Phrase eingeben, um ohne erneute Token-Karte wieder auf Ihr bestehendes Konto zuzugreifen. Falls die Phrase mehrfach falsch eingegeben wird, sperrt die App die Wiederherstellung vorübergehend — versuchen Sie es später erneut oder wenden Sie sich an Ihren Studienkoordinator.

---

## 2. Eine Gewohnheit spenden

Eine Gewohnheit zu spenden bedeutet, eine Ihrer alltäglichen Routinen mit dem Forschungsprojekt zu teilen — zum Beispiel: _„Ich trinke jeden Morgen direkt nach dem Aufwachen ein Glas Wasser."_ Alle Spenden sind anonym.

**Schritt 1.** Tippen Sie unten auf die Registerkarte **Spenden**.

**Schritt 2.** Der Gewohnheitsfragebogen wird geladen. Folgen Sie den Anweisungen auf dem Bildschirm, um Ihre Gewohnheit zu beschreiben.

**Schritt 3.** Tippen Sie auf **Senden**. Sobald Ihre Gewohnheit gespeichert wurde, erhalten Sie eine Bestätigung; die Analyse läuft im Hintergrund weiter, es kann also einen Moment dauern, bis die Gewohnheit in **Erkunden** erscheint.

Sie können mehrere Gewohnheiten spenden — tippen Sie nach jeder Einreichung einfach erneut auf **Spenden**.

---

## 3. Ihre Gewohnheiten ansehen

Die Registerkarte **Erkunden** zeigt die von Teilnehmern gespendeten Gewohnheiten.

**Schritt 1.** Tippen Sie unten auf die Registerkarte **Erkunden**.

**Schritt 2.** Durchstöbern Sie die angezeigten Gewohnheiten. Tippen Sie auf eine Gewohnheit, um mehr darüber zu lesen — dort können Sie sie auch **liken** und, sofern die Kommentarfunktion für Ihre Studie aktiviert ist, einen **Kommentar** hinterlassen. Kommentare sind anonym und werden vor der Veröffentlichung automatisch auf unangemessene Inhalte geprüft.

---

## 4. Einstellungen

Tippen Sie auf das **Einstellungen**-Symbol (meist oben im Bildschirm), um auf Folgendes zuzugreifen:

- **Sprache** — wechseln Sie die Anzeigesprache der App (Englisch, Deutsch, Französisch, Japanisch, Niederländisch).
- **Rechtliches** — unter **Einstellungen → Rechtliches** finden Sie die Nutzungsbedingungen, die Datenschutzerklärung und das Impressum.
- **Konto löschen** — löscht dauerhaft alle mit Ihrem Konto verknüpften Daten (Profil, Fragebogenantworten, Empfehlungen, Ihre Kommentare) sowie Ihre Anmeldedaten. Anonym gespendete Gewohnheiten bleiben bestehen, da sie ohnehin keine Kennung Ihres Kontos enthalten. Diese Aktion kann nicht rückgängig gemacht werden.

Falls Ihre Studie das erweiterte Gewohnheitsmodul (implementation intentions, tägliche Protokollierung, wöchentliche Check-ins) nutzt, finden Sie diese Funktionen unter der Registerkarte **Meine Gewohnheiten**.

---

## 5. Wenn etwas nicht funktioniert

| Problem                                                                            | Was zu tun ist                                                                                                       |
| ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| QR-Code kann nicht gescannt werden                                                 | Geben Sie Benutzername und Passwort von Ihrer Token-Karte manuell ein                                                |
| App zeigt „Ungültige Anmeldedaten"                                                 | Prüfen Sie, ob Sie Benutzername und Passwort genau wie aufgedruckt eingegeben haben (Groß-/Kleinschreibung beachten) |
| App verbindet sich nicht                                                           | Prüfen Sie Ihre WLAN- oder Mobilfunkverbindung und versuchen Sie es erneut                                           |
| Ich weiß nicht, welches Konto meins ist                                            | Fragen Sie Ihren Studienkoordinator — er kann es für Sie nachschlagen                                                |
| Ich habe meine Token-Karte verloren und kenne meine Wiederherstellungsphrase nicht | Wenden Sie sich an Ihren Studienkoordinator für eine Ersatzkarte                                                     |

---

## 6. Teilnahme beenden

Sie können die Nutzung der App jederzeit beenden — hören Sie einfach auf, sie zu öffnen. Ein Löschen des Kontos oder eine Benachrichtigung ist nicht erforderlich. Bereits gespendete Daten verbleiben in pseudonymisierter Form in der Studie, wie in der Datenschutzerklärung beschrieben (**Einstellungen → Rechtliches**). Wenn Sie stattdessen Ihre Daten vollständig löschen möchten, nutzen Sie **Konto löschen** (siehe Abschnitt 4).

---

## Fragen?

Wenn Sie Fragen haben oder auf ein hier nicht behandeltes Problem stoßen, wenden Sie sich an Ihren Studienkoordinator über die Kontaktdaten auf Ihrer Token-Karte oder in Ihrer Einladungs-E-Mail.

Vielen Dank für Ihre Teilnahme am Health Habit Hub Forschungsprojekt.
