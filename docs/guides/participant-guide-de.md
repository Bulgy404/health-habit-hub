## 1. Zugriff auf die App

Sie können Health Habit Hub auf Android, iOS oder direkt in Ihrem Browser verwenden – keine Kontoregistrierung erforderlich.

### Android (APK-Installation)

**Schritt 1.** Laden Sie die neueste APK-Datei über den vom Studienteam bereitgestellten Link herunter (z. B. in Ihrer Einladungs-E-Mail).

**Schritt 2.** Öffnen Sie auf Ihrem Android-Smartphone **Einstellungen → Sicherheit** und aktivieren Sie **Installation aus unbekannten Quellen** (oder **Von dieser Quelle erlauben** für Ihren Browser).

**Schritt 3.** Öffnen Sie die heruntergeladene APK-Datei und tippen Sie auf **Installieren**. Tippen Sie auf **Öffnen**, wenn die Installation abgeschlossen ist.

**Schritt 1.** Verwenden Sie den vom Studienteam bereitgestellten Link in Safari auf Ihrem iPhone oder iPad.

**Schritt 2.** Folgen Sie den Anweisungen auf dem Bildschirm, um die App über TestFlight zu installieren oder die Browserversion zu öffnen.

**Schritt 1.** Öffnen Sie Chrome oder Firefox und navigieren Sie zur URL, die Ihr Studienkoordinator angegeben hat (z. B. `https://hhh.tu-dresden.de`).

**Schritt 2.** Sie können die App optional zum **Startbildschirm hinzufügen** – tippen Sie auf das Teilen-Symbol in Safari/Chrome und wählen Sie **Zum Startbildschirm**.

## 2. Anmelden mit Ihrer Token-Karte

Das Studienteam gibt Ihnen eine **Token-Karte** – eine kleine Karte mit einem QR-Code sowie einem gedruckten Benutzernamen und Passwort. Sie müssen sich kein Passwort merken oder selbst wählen.

**Schritt 1.** Öffnen Sie die App. Sie sehen den **Health Habit Hub**-Anmeldebildschirm mit einem türkisfarbenen Schildsymbol sowie einem Feld für **Benutzername** und **Passwort**.

**Schritt 2 (QR-Scan – nur Android/iOS).** Tippen Sie auf die QR-Scan-Schaltfläche, falls vorhanden, und richten Sie Ihre Kamera auf den QR-Code auf Ihrer Token-Karte. Die Felder für Benutzername und Passwort werden automatisch ausgefüllt.

**Schritt 3 (manuelle Eingabe).** Falls der QR-Scan nicht verfügbar ist oder Sie einen Browser verwenden, tippen Sie Benutzername und Passwort genau so ein, wie sie auf Ihrer Token-Karte gedruckt sind. Benutzernamen sehen aus wie `hhh-1234`.

**Schritt 4.** Tippen Sie auf **Anmelden**. Kurz erscheint ein Ladekreisel, während die App eine Verbindung zum Server herstellt. Anschließend gelangen Sie zum Hauptbildschirm.

## 3. Ihr Profil ausfüllen

Bevor Sie Gewohnheiten spenden oder Empfehlungen erhalten können, müssen Sie einen kurzen Profilfragebogen ausfüllen. Dies hilft uns, Ihr Erlebnis zu personalisieren.

**Schritt 1.** Tippen Sie nach dem Anmelden auf die Registerkarte **Profil** am unteren Bildschirmrand (Symbol: Person).

**Schritt 2.** Der Profilfragebogen wird in der App geladen. Er stellt einige kurze Fragen zu Ihrem Hintergrund – zum Beispiel zu Ihrer Altersgruppe und wie häufig Sie Sport treiben. Alle Antworten sind anonym.

**Schritt 3.** Beantworten Sie jede Frage und tippen Sie auf **Weiter**, um zur nächsten Seite zu gelangen.

**Schritt 4.** Wenn Sie die letzte Seite erreichen, tippen Sie auf **Senden**. Sie sehen ein grünes Häkchen und die Nachricht **Profil ausgefüllt** mit dem heutigen Datum.

## 4. Eine Gewohnheit spenden

Eine Gewohnheit zu spenden bedeutet, eine Ihrer alltäglichen Routinen mit dem Forschungsprojekt zu teilen. Zum Beispiel: *„Ich putze mir nach dem Aufwachen jeden Morgen die Zähne."* Alle Spenden sind anonym.

**Schritt 1.** Tippen Sie auf die Registerkarte **Spenden** am unteren Bildschirmrand (Symbol: Geschenk).

**Schritt 2.** Der Gewohnheitsspenden-Fragebogen wird geladen. Je nachdem, in welcher Studiengruppe Sie sich befinden, sehen Sie möglicherweise ausführliche Anweisungen oder nur ein einfaches Textfeld – das ist beabsichtigt.

**Schritt 3.** Beschreiben Sie Ihre Gewohnheit im Textfeld. Seien Sie so präzise wie möglich: Geben Sie an, was Sie tun, wann Sie es tun und wo.

**Schritt 4.** Falls Sie dazu aufgefordert werden, verwenden Sie die Schaltflächen unterhalb des Textfelds, um Wörter als **Verhalten** (die Handlung, die Sie ausführen) oder **Kontext** (wann oder wo es geschieht) zu markieren. Tippen Sie auf ein Wort oder eine Phrase in Ihrem Text, um es auszuwählen, und tippen Sie dann auf die entsprechende Schaltfläche.

**Schritt 5.** Tippen Sie unten auf **Senden**. Kurz erscheint eine Bestätigungsnachricht – **Gewohnheit erfolgreich gespendet!**

## 5. Den Gewohnheitsgraphen erkunden und Knoten kommentieren

Die Registerkarte **Erkunden** zeigt Ihnen einen interaktiven Graphen aller von Teilnehmern gespendeten Gewohnheiten. Sie können Knoten durchsuchen und kommentieren, um Forschern bei der Klassifizierung von Gewohnheiten zu helfen.

**Schritt 1.** Tippen Sie auf die Registerkarte **Erkunden** am unteren Bildschirmrand.

**Schritt 2.** Der Gewohnheitsgraph wird geladen. Sie sehen nach Kategorie gruppierte Gewohnheitsknoten. Verwenden Sie den **Kategoriefilter** oben, um die angezeigten Gewohnheiten einzugrenzen.

**Schritt 3.** Tippen Sie auf einen beliebigen Gewohnheitsknoten, um eine Detailansicht zu öffnen. Sie können die Gewohnheitsbeschreibung lesen und sehen, wie andere Teilnehmer sie kommentiert haben.

**Schritt 4 (Kommentieren).** Tippen Sie in der Detailansicht auf die Kommentierungsschaltflächen – z. B. **Verhalten** oder **Kontext** – um einen Teil des Gewohnheitstextes zu klassifizieren. Ihre Kommentierung wird automatisch gespeichert.

**Schritt 5.** Scrollen Sie durch den Graphen, um weitere Gewohnheiten zu entdecken. Sie können auf Touchscreens durch Zusammendrücken der Finger hinein- und herauszoomen.

## 6. Ihre Empfehlungen verstehen

Nachdem Sie Ihr Profil ausgefüllt und mindestens eine Gewohnheit gespendet haben, zeigt die Registerkarte **Empfehlen** personalisierte Gewohnheitsvorschläge basierend auf Ihrem Profil und Ihren gespendeten Gewohnheiten.

**Schritt 1.** Tippen Sie auf die Registerkarte **Empfehlen** am unteren Bildschirmrand.

**Schritt 2.** Eine Liste von Empfehlungskarten erscheint. Jede Karte zeigt:
- **Name der Gewohnheit** – eine kurze Beschreibung der vorgeschlagenen Gewohnheit.
- **Kategorie** – die Verhaltenskategorie (z. B. Sport, Schlaf, Ernährung).
- **Begründung** – warum diese Gewohnheit für Sie empfohlen wurde, in einfacher Sprache erklärt.
- **Quellenangabe** – der Forschungsverweis, der diese Empfehlung unterstützt.

**Schritt 3.** Für jede Empfehlung können Sie:
- Auf **Annehmen** tippen, um sie Ihrer persönlichen Gewohnheitsliste hinzuzufügen.
- Auf **Ablehnen** tippen, um sie aus Ihrer Liste zu entfernen.

Neue Empfehlungen erscheinen automatisch, wenn das System neue Übereinstimmungen findet – Sie sehen einen Live-Indikator-Punkt in der oberen rechten Ecke des Bildschirms (grün = live, grau = Abfrage alle paar Minuten).

## 7. Ihr Profil aktualisieren

Sie können Ihr Profil jederzeit aktualisieren, wenn sich Ihre Umstände ändern.

**Schritt 1.** Tippen Sie auf die Registerkarte **Profil** am unteren Bildschirmrand.

**Schritt 2.** Wenn Sie Ihr Profil bereits ausgefüllt haben, sehen Sie eine **Profil ausgefüllt**-Karte mit einem grünen Häkchen und dem Datum, an dem Sie es ausgefüllt haben.

**Schritt 3.** Tippen Sie auf die Schaltfläche **Bearbeiten** auf der Karte.

**Schritt 4.** Der Profilfragebogen öffnet sich erneut mit Ihren vorherigen Antworten vorausgefüllt. Aktualisieren Sie alle Antworten, die sich geändert haben.

**Schritt 5.** Tippen Sie auf **Senden**, wenn Sie fertig sind. Ihr Profil wird gespeichert und die Karte zeigt das neue Abschlussdatum.
